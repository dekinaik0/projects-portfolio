# Портфолио: Python, SQL, аналитика данных, ML

Шесть пет-проектов по работе с данными: от SQL-аналитики и автоматизации отчётности до ML-скоринга на CatBoost, статистической проверки гипотез и интерактивного дашборда. Каждый проект лежит в отдельной папке, имеет свой README и запускается независимо.

## Проекты

| Проект | О чём | Стек |
|---|---|---|
| [01 — SQL-аналитика интернет-магазина](01-sql-shop-analytics) | Схема БД, 10 запросов от агрегаций до оконных функций, продуктовые метрики и дашборд | SQLite, pandas, matplotlib |
| [02 — Классификация отзывов](02-review-classifier) | Размеченный датасет, TF-IDF + LinearSVC, кросс-валидация, precision/recall/F1 и разбор ошибок | scikit-learn, pandas, matplotlib |
| [03 — Автоматизация отчёта по заявкам](03-report-automation) | Очистка «грязной» выгрузки, расчёт SLA и метрик поддержки, сборка Excel-отчёта с графиками | pandas, openpyxl |
| [04 — Кредитный скоринг на CatBoost](04-credit-scoring) | Модель вероятности дефолта, сравнение с baseline, ROC-AUC, важность признаков, работа с дисбалансом классов | CatBoost, scikit-learn, pandas, matplotlib |
| [05 — Анализ A/B-теста](05-ab-test) | Z-тест для разности пропорций, доверительные интервалы, проверка через chi-квадрат, расчёт нужного размера выборки | SciPy, pandas, matplotlib |
| [06 — Дашборд по результатам скоринга](06-scoring-dashboard) | Интерактивный веб-дашборд с фильтрами и настраиваемым порогом отсечения поверх модели из проекта 04 | Streamlit, pandas, matplotlib |

## Что демонстрируют проекты

**SQL** — JOIN, CTE, оконные функции (`RANK`, `SUM OVER`), агрегации, группировка по датам, расчёт retention и среднего чека.

**Python и работа с данными** — очистка сырых данных, разбор неоднородных форматов, агрегации и разрезы в pandas, выгрузка в Excel с диаграммами.

**ML** — векторизация текста и градиентный бустинг на табличных данных, работа с категориальными признаками и дисбалансом классов, выбор схемы валидации, интерпретация метрик по классам.

**Статистика** — проверка гипотез, доверительные интервалы, различие между «эффекта нет» и «данных недостаточно», расчёт необходимого размера выборки.

**Оценка качества** — не только «модель работает», но и где именно она ошибается, какие классы путает и что из этого стоит отдавать на ручную проверку.

**Представление результатов** — от статичного дашборда-картинки до интерактивного веб-инструмента, где заказчик сам крутит фильтры и порог принятия решения.

## Данные

Во всех проектах данные синтетические и генерируются скриптами с фиксированным `random.seed`. Это сделано намеренно: набор воспроизводится у любого, кто клонирует репозиторий, и в него можно заложить ровно те дефекты или закономерности, на которых интересно показать логику обработки — дубли, разные форматы дат, пропуски, реалистичный дисбаланс классов.

## Как запускать

Каждая папка самодостаточна:

```bash
cd 01-sql-shop-analytics
pip install -r requirements.txt
python create_db.py
python metrics.py
```

Точные команды для остальных проектов — в их README. Проект 06 использует результаты проекта 04, но включает собственную копию данных и запускается независимо.
