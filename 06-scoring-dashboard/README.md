# Интерактивный дашборд по результатам скоринга

Веб-дашборд на Streamlit для представления результатов модели кредитного скоринга нетехническому заказчику — с фильтрами, метриками и списком заявок повышенного риска.

Использует результаты проекта [04 — Кредитный скоринг на CatBoost](../04-credit-scoring): `scored_applications.csv` — это тестовая выборка с предсказанными вероятностями дефолта.

## Задача

Модель обучена, метрики посчитаны — но аналитик или руководитель отдела не будет читать `predictions.csv` и запускать Python. Ему нужен инструмент, где можно покрутить фильтры и сразу увидеть, что происходит с конкретным срезом заявок.

## Стек

Python 3, Streamlit, pandas, matplotlib.

## Структура

| Файл | Назначение |
|---|---|
| `scored_applications.csv` | Тестовая выборка с предсказаниями модели (перенесена из проекта 04) |
| `dashboard.py` | Дашборд: фильтры, метрики, графики, таблица высокого риска |

## Запуск

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

Откроется браузер на `localhost:8501`.

## Что внутри

**Фильтры в боковой панели** — регион, тип занятости, возраст, и отдельно порог отсечения по вероятности дефолта. Порог вынесен в отдельный слайдер намеренно: в проекте 04 показано, что выбор порога — это компромисс между тем, сколько дефолтов модель ловит и сколько надёжных клиентов ошибочно помечает рискованными. Заказчику часто нужно покрутить этот порог самому, а не получить один зафиксированный вариант.

**Карточки метрик** — количество заявок в текущем срезе, средняя вероятность дефолта, число заявок с высоким риском при выбранном пороге, число фактических дефолтов в выборке. Обновляются вместе с фильтрами.

**Распределение вероятности дефолта** — гистограмма отдельно для дефолтных и недефолтных заявок с вертикальной линией текущего порога. Видно, где проходит граница и сколько заявок на неё попадает.

**Средний риск по типу занятости** — простой разрез, показывающий, какие группы заявителей рискованнее в среднем.

**Таблица высокого риска** — конкретные заявки, попавшие выше порога, отсортированные по убыванию вероятности. То, что аналитик будет разбирать вручную.

**Кнопка выгрузки** — отфильтрованный срез можно скачать в CSV, чтобы унести в Excel или переслать коллеге.

## Почему Streamlit, а не статичный график

Проект 01 в портфолио уже показывает дашборд как картинку (`dashboard.png`) — там метрики фиксированы на момент построения. Здесь задача другая: у заказчика есть право задать вопрос «а что если только Москва» или «а что если порог не 0.5, а 0.3», и получить ответ сразу, без обращения к аналитику. Streamlit даёт такой интерфейс при минимуме кода — весь дашборд укладывается в один файл без фронтенд-разработки.

## Возможные доработки

- Кэширование данных (`st.cache_data`) при переходе на источник данных большего объёма
- Сравнение нескольких версий модели на одной странице
- Экспорт не только CSV, но и готового PDF-отчёта по срезу
- Авторизация, если дашборд выкладывается не только для внутреннего пользования
