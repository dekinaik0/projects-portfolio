# Автоматизация отчёта по заявкам

Скрипт превращает «грязную» выгрузку обращений в готовый Excel-отчёт с метриками и графиками. Ручной работы — ноль, запуск одной командой.

## Задача

Типичная выгрузка из внутренней системы не готова к анализу:

- дубли строк после повторных выгрузок
- две разные записи дат в одном столбце: `2024-09-16 14:30` и `16.09.2024 14:30`
- отделы в произвольном регистре и с лишними пробелами: `Доставка`, `доставка`, `ПОДДЕРЖКА`, `Оплата `
- оценки текстом вперемешку с числами: `5`, `5 из 5`, `нет оценки`, пусто
- пустые значения там, где заявка ещё не закрыта

Скрипт всё это чинит и считает метрики, которые нужны руководителю отдела.

## Стек

Python 3, pandas, openpyxl.

## Структура

| Файл | Назначение |
|---|---|
| `raw_tickets.csv` | Исходная выгрузка: 318 строк со всеми типичными проблемами |
| `build_report.py` | Очистка, расчёт метрик, сборка `report.xlsx` |

## Запуск

```bash
pip install -r requirements.txt
python build_report.py
```

На выходе — `report.xlsx` с четырьмя листами и двумя встроенными графиками.

## Что делает скрипт

**Очистка**

1. Удаляет дубли строк
2. Приводит названия отделов к единому виду: обрезает пробелы, нормализует регистр
3. Разбирает даты по двум известным форматам и объединяет результат
4. Вытаскивает из поля оценки только корректные числа, остальное помечает как пропуск
5. Считает время решения как разницу между закрытием и созданием

**Метрики**

- Всего заявок, распределение по статусам
- Среднее и медианное время решения
- Доля заявок, уложившихся в SLA 24 часа
- Средняя оценка и число заявок без оценки
- Разрезы по отделам, типам обращений и неделям

**Отчёт**

| Лист | Содержимое |
|---|---|
| Сводка | Ключевые цифры одним списком |
| По отделам | Заявки, время решения, SLA и оценка в разрезе отделов + гистограмма |
| По типам | Распределение обращений по типам |
| По неделям | Динамика числа заявок + линейный график |

Ширина колонок подгоняется автоматически, графики строятся средствами openpyxl и живут внутри файла как настоящие диаграммы Excel, а не как вставленные картинки.

## Пример результата

```
Загружено строк: 318
Удалено дублей: 18

                   Метрика  Значение
              Всего заявок       300
                    Решено       176
  Среднее время решения, ч      24.6
Медианное время решения, ч      14.8
        Доля в SLA 24 ч, %      72.2
```

Разрыв между средним и медианой показателен: половина заявок закрывается за 15 часов, но длинный хвост из редких долгих разборов вытягивает среднее почти до 25. По одному только среднему картина выглядела бы хуже, чем есть, — поэтому в отчёте есть обе цифры.

## Отдельно про разбор дат

Первая версия использовала `pd.to_datetime(..., format="mixed", dayfirst=True)`, и это оказалось ловушкой: флаг `dayfirst` применяется и к ISO-датам тоже, поэтому `2024-09-06` превращалось в 9 июня. Средние значения при этом выглядели правдоподобно, а отдельные заявки получали отрицательное время решения.

Итоговое решение — разобрать оба формата явно и объединить результаты:

```python
iso = pd.to_datetime(series, format="%Y-%m-%d %H:%M", errors="coerce")
ru = pd.to_datetime(series, format="%d.%m.%Y %H:%M", errors="coerce")
return iso.fillna(ru)
```
